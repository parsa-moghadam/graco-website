# وب‌سایت GRACO — نسخه آغازین

این پوشه، نسخه اولیه قابل اجرا برای طراحی اختصاصی سایت GRACO است. این پروژه فروشگاه اینترنتی نیست؛ یک وب‌سایت معرفی برند و کاتالوگ تصویری است.

## پیش‌نیاز
- ویندوز 10 یا 11
- Node.js نسخه LTS (نسخه 20.9 یا جدیدتر)
- اینترنت برای نصب اولیه پکیج‌ها

## اجرای پروژه در ویندوز
1. Node.js LTS را از سایت رسمی نصب کن: https://nodejs.org/en/download
2. بعد از نصب، CMD یا PowerShell را ببند و دوباره باز کن.
3. وارد پوشه‌ای شو که این پروژه را از ZIP خارج کرده‌ای.
4. در نوار آدرس File Explorer بنویس `cmd` و Enter بزن تا CMD دقیقاً در همان پوشه باز شود.
5. این دو دستور را جداگانه اجرا کن:

```cmd
npm install
npm run dev
```

6. مرورگر را باز کن و برو به:

```text
http://localhost:3000
```

## خاموش کردن و اجرای دوباره
- برای متوقف کردن سایت در CMD کلیدهای `Ctrl + C` را بزن.
- برای اجرای دوباره، CMD را در پوشه پروژه باز کن و اجرا کن: `npm run dev`

## ویرایش صفحه اصلی
- محتوای صفحه: `app/page.tsx`
- ظاهر و رنگ‌ها: `app/globals.css`
- لوگو: `public/graco-logo.svg`

این نسخه یک نقطه شروع طراحی است. تصویر صنعتی بخش اول فعلاً با گرافیک موقت ساخته شده و در مرحله بعد با تصویر فوتورئالیستی اختصاصی جایگزین می‌شود. اطلاعات تماس و جزئیات تأییدنشده عمداً به‌عنوان اطلاعات واقعی نمایش داده نشده‌اند.
